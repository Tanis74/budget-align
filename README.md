# budget-align

Мини-калькулятор для выравнивания совместного бюджета по трём категориям.
Открывать: **https://tanis74.github.io/budget-align/**

## Правила

- Категории и лимиты на человека: **Продукты — 20 000 ₽**, **Еда вне дома — 10 000 ₽**, **Развлечения — 5 000 ₽** (лимиты редактируются на странице).
- В каждой категории остатки счетов А и Б **выравниваются**: у кого больше — переводит половину разницы; при нечётной сумме лишний рубль достаётся тому, у кого было меньше.
- Продукты и еда вне дома после выравнивания **дополняются каждым до лимита** из своих денег.
- Развлечения: после выравнивания каждому **безусловно +5 000 ₽** — не потраченное копится.
- Вводятся только целые рубли; пустое поле = 0; отрицательный остаток допустим (перерасход).
- Результат: один **нетто-перевод** между счетами (кто кому и сколько) + сумма доплат каждому.
- **Перерасход за месяц** — сумма минусовых итогов по категориям (остатки А и Б в сумме ниже нуля); плюс одной категории не погашает минус другой.

## Технически

Один самодостаточный `index.html` без зависимостей и сборки, данных не хранит.
